The Problem

⚠️

Safety Risk

Undetected track defects cause derailments, infrastructure damage, and passenger injuries. Manual inspection is slow and inconsistent.

🕒

Slow Inspection

Traditional human inspections cover only a few kilometers per day, leaving the network vulnerable between surveys.

💵

High Cost

Delays in defect detection lead to expensive emergency repairs, line closures, and liability claims.

The Solution

🎥 Video-Based Detection

Upload a track inspection video. The system processes every frame with a YOLOv8 model and draws bounding boxes on each defect in real time.

Launch →

📊 Inspection Analytics

Per-frame defect count, type distribution, severity classification (Low / Medium / High), and a downloadable annotated video for reports.

Dataset

Railway Track Surface Defects Dataset

Roboflow Universe — Object Detection (v11)

  • 2,644 annotated images (2,319 train / 325 val)
  • 7 defect classes: Cracks, Flakings, Grooves, Joint, Shellings, Spallings, Squats
  • YOLOv8 bounding box format
  • CC BY 4.0
